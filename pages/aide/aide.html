Questions fréquentes (FAQ)

Pour effectuer un virement depuis votre espace client SkyDash Bank :

  1. Rendez-vous dans la section Virements du menu principal.
  2. Sélectionnez le compte débiteur (compte depuis lequel vous souhaitez virer).
  3. Choisissez un bénéficiaire dans votre liste ou saisissez un IBAN destinataire.
  4. Indiquez le montant et la date d'exécution (immédiat ou différé).
  5. Validez l'opération via votre code SMS (DSP2 obligatoire pour tout virement).

Les virements SEPA sont généralement exécutés en 1 jour ouvré. Les virements instantanés sont disponibles 24h/24, 7j/7, avec une limite de 15 000 € par opération.

Vous pouvez bloquer votre carte bancaire de deux façons :

  • Blocage temporaire (réversible) : Allez dans Mes Cartes, sélectionnez la carte concernée et cliquez sur "Bloquer temporairement". Le blocage est immédiat et vous pouvez le lever à tout moment.
  • Opposition (perte/vol) : Pour une opposition définitive suite à une perte ou un vol, utilisez le bouton "Signaler une perte" dans la section Mes Cartes, ou appelez le 0 892 705 705 (numéro interbancaire, disponible 24h/24, 7j/7).
En cas de vol avec utilisation frauduleuse, déposez également plainte auprès de la police et transmettez-nous le récépissé.

Pour ajouter un nouveau bénéficiaire à votre carnet d'adresses bancaire :

  1. Accédez à la section Bénéficiaires dans le menu.
  2. Cliquez sur le bouton "+ Ajouter un bénéficiaire".
  3. Saisissez l'IBAN du bénéficiaire, son nom et un alias optionnel.
  4. Validez la demande. Vous recevrez un code de confirmation par SMS.
  5. Le bénéficiaire sera disponible pour des virements sous 24 à 72 heures (délai réglementaire).

Ce délai d'activation est imposé par la réglementation bancaire pour protéger vos fonds contre les ajouts frauduleux.

La DSP2 (Directive des Services de Paiement 2) est une réglementation européenne entrée en vigueur en 2019, qui renforce la sécurité des paiements en ligne.

Elle impose l'authentification forte du client (SCA — Strong Customer Authentication) pour :

  • Les connexions à votre espace bancaire en ligne
  • Les virements bancaires
  • Les paiements en ligne supérieurs à 30 €
  • L'ajout ou la modification de bénéficiaires

L'authentification forte repose sur au moins 2 facteurs parmi 3 : ce que vous savez (mot de passe/PIN), ce que vous possédez (téléphone mobile), ce que vous êtes (biométrie).

Chez SkyDash Bank, cette authentification se fait généralement via un code SMS à 6 chiffres ou via notre application mobile avec validation biométrique.

Le 2FA est activé par défaut sur votre compte SkyDash Bank (via SMS), conformément à la réglementation DSP2. Pour le configurer ou changer de méthode :

  1. Accédez à la section Sécurité depuis le menu.
  2. Dans le bloc "Authentification à deux facteurs", cliquez sur "Gérer le 2FA".
  3. Choisissez votre méthode préférée : SMS, application TOTP (Google Authenticator, Authy) ou clé de sécurité physique (FIDO2).
  4. Suivez les instructions à l'écran pour valider la nouvelle méthode.
Nous déconseillons fortement de désactiver le 2FA, car cela réduirait significativement la protection de votre compte.

Pour télécharger vos relevés de compte :

  1. Allez dans la section Mes Comptes ou Historique des transactions.
  2. Sélectionnez le compte pour lequel vous souhaitez un relevé.
  3. Cliquez sur le bouton "Télécharger le relevé" ou utilisez les filtres de date pour sélectionner la période souhaitée.
  4. Choisissez le format : PDF (format officiel, signé électroniquement) ou CSV (pour import dans un logiciel comptable).

Vos relevés sont également envoyés automatiquement chaque mois à votre adresse email si vous avez activé cette option dans vos Préférences.

Les relevés sont disponibles sur 10 ans d'historique depuis votre espace client, conformément aux obligations légales de conservation des documents bancaires.
